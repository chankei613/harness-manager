機能

AIの実行権限を、
安全に運用するために必要なもの

settings.json を手で編集しなくていい。名前を付けたプロファイルとして権限を管理できます。

Harness Profile

permissions・hooks・env をひとつの名前付きプロファイルにまとめて管理。プロジェクトやエージェントごとに切り替えられます。

組み込みプリセット4種

readonly / backend-dev / prod-safe / full-auto をワンクリックで導入。そこから調整して自分用のプロファイルにできます。

ワイルドカード権限ルール

allow Bash(*) や deny Bash(git push --force*) のように、許可/拒否ルールを柔軟に指定できます。

Hooks でブロックも可能

PreToolUse / PostToolUse / Stop / Notification にシェルコマンドを紐付け。blocking: true で危険な操作を強制的に止められます。

JSONライブプレビュー

エクスポート前に、生成される settings.json の中身をその場で確認できます。書き出してから中身を見て驚くことがありません。

Import / Export

既存の settings.json を読み込んでプロファイル化。編集後は好きな .claude/ フォルダへ書き出せます。
